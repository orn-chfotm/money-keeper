# plan 인덱스

사용자 승인 전에 검토할 구현 계획을 보관한다. 승인 대기·승인·반려 상태를 각 문서 상단에 적는다.

## 파일 명명 규칙

- `YYYY-MM-DD-NN-{slug}.md`
- `NN`은 같은 날짜 안의 순번(`01`, `02`, ...)이다.
- 모든 문서 상단에 frontmatter `description`을 둔다.

## 파일 목록

- `2026-10-15-01-stage2-calendar-title.md`: 2단계 보완 — 월 달력 화면과 기록 제목(title) 추가 (승인 대기)
