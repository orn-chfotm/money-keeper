# 미정 사항

## 구현 전 결정할 사항

| 질문 | 선택지 및 차이 |
| --- | --- |
| 급여일 기준 통계 | 기준일~다음 기준일 전날 구간은 제안 상태. 반복 수입의 등록일과 별개로 통계 기준일을 설정하는 방법, 최초 미설정 상태, 기준일 변경 시 과거 주기 보존 방식 결정 필요 |
| 인증·배포 방식 | 단일 사용자 사용은 확정. 인증과 배포 방식은 외부 배포 전에 다시 결정 필요 |

## 확정된 사항

- 은행 연동 없이 개인 수입·지출·저축을 기록한다.
- 단일 사용자로 쓴다. 인증이 정해지기 전까지 기록에 사용자 구분 정보를 두지 않고, 외부에 배포하지 않는다.
- 저축 인출은 초기 범위에서 제외한다.
- 급여 외 기타 수입을 지원한다. 모든 수입·지출·저축은 등록·수정·삭제할 수 있다.
- 저축은 기간 잔여액에서 차감하고 소비 지출과 별도로 집계한다. 잔액은 이월하지 않는다.
- 일반 기록은 직접 입력한다. 반복 설정한 수입·지출은 매주·매월·매년 예정일에 자동 등록한다. 저축의 반복 등록은 초기 범위에서 제외한다.
- 반복 설정 변경은 다음 예정 회차부터 적용한다. 이미 등록된 기록은 직접 수정하며, 개별 기록 수정·삭제는 반복 설정에 영향을 주지 않는다.
- 반복 날짜가 없는 달·연도에는 해당 월 말일에 등록하고, 이후 회차는 원래 지정한 날짜를 사용한다.
- 누락 회차 보충, 중복 방지, 삭제 회차 재생성 방지, 반복 중단 기준은 [계산 및 통계 정책](04-calculation-and-statistics.md)을 따른다.
