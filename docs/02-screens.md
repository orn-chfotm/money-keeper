# 화면 구성

## 최소 화면 구성 제안

| 화면 | 내용 |
| --- | --- |
| 가계부 | 현재 급여 주기 요약, 일별 기록 목록, 수입(급여·기타)·지출·저축 입력 및 수정·삭제. 자동 등록된 기록도 수정·삭제 가능 |
| 통계 | 급여 주기·월·연 선택, 기간별 합계, 연간 월별 표 |
| 반복 설정 | 이름·설명, 수입·지출 구분, 수입 종류, 금액, 매주·매월·매년 주기와 시작일 입력·조회·변경, 이후 자동 등록 중단 |
| 통계 기준 설정 | 통계용 급여 기준일 설정. 설정·변경 정책 확정 후 구체화 |

가계부와 통계에는 실제 계좌 잔고 대신 집계 기간과 기간 잔여액을 표시한다. 반복 설정 변경은 다음 예정 회차부터 적용되고, 과거 기록은 가계부에서 직접 수정한다는 점을 안내한다. 개별 기록 삭제와 이후 반복 등록 중단은 별도 동작으로 제공한다.
