# 화면 구성

## 최소 화면 구성 제안

| 화면 | 내용 |
| --- | --- |
| 가계부 | 현재 급여 주기 요약, 월 달력과 날짜별 기록, 달력 하단 날짜 상세 영역에서 수입(급여·기타)·지출·저축 확인·삭제, 등록·수정은 폼 팝업. 자동 등록된 기록도 수정·삭제 가능 |
| 통계 | 급여 주기·월·연 선택, 기간별 합계, 연간 월별 표 |
| 반복 설정 | 이름·설명, 수입·지출 구분, 수입 종류, 금액, 매주·매월·매년 주기와 시작일 입력·조회·변경, 이후 자동 등록 중단 |
| 통계 기준 설정 | 통계용 급여 기준일 설정. 설정·변경 정책 확정 후 구체화 |

가계부와 통계에는 실제 계좌 잔고 대신 집계 기간과 기간 잔여액을 표시한다. 반복 설정 변경은 다음 예정 회차부터 적용되고, 과거 기록은 가계부에서 직접 수정한다는 점을 안내한다. 개별 기록 삭제와 이후 반복 등록 중단은 별도 동작으로 제공한다.

## 가계부 화면

### 월 달력

- 첫 화면은 한국 시간 기준 현재 월로 열고 오늘 날짜를 선택한다. 이전·다음 월로 이동할 수 있다.
- 월을 이동하면 오늘이 속한 달은 오늘, 그 외의 달은 1일을 선택한다.
- 일요일부터 시작하는 주 단위 달력이다. 앞뒤 달 날짜는 흐린 숫자만 보여주고 기록 표시와 선택은 하지 않는다.
- 칸에는 그날 기록을 구분별 건수로만 보여준다. 넓은 화면은 `수입 1건`처럼 줄 단위로, 좁은 화면은 `수1`처럼 구분 글자와 건수를 담은 색 배지로 보여준다. 0건인 구분은 표시하지 않는다.
- 구분은 수입 초록, 지출 빨강, 저축 보라로 표시한다. 색만으로 구분하지 않도록 구분 글자를 함께 보여준다.
- 선택한 날짜 칸은 옅은 배경과 강조 테두리로, 오늘은 날짜 숫자에 약한 링으로 표시한다. 두 표시는 서로 별개다.
- 토요일은 요일과 날짜 숫자를 파랑, 일요일은 빨강으로 표시한다. 현재 달 칸에만 적용하고 앞뒤 달 날짜는 흐린 색을 유지한다.
- 날짜 칸은 "10월 15일, 수입 1건 지출 2건" 또는 "10월 15일, 기록 없음"처럼 날짜와 구분별 건수를 읽을 수 있는 버튼으로 제공한다.

### 날짜 상세 영역과 입력 팝업

- 날짜를 선택하면 달력 아래 날짜 상세 영역에 그날 기록을 보여준다. 날짜 선택만으로 팝업을 열지 않는다.
- 상세 영역은 날짜 제목, 등록 버튼, 수입→지출→저축 구역으로 구성한다. 기록이 없는 구역은 숨기고, 구역 안 기록은 등록순(먼저 등록한 기록부터)으로 보여준다.
- 각 기록은 제목, 구분(수입은 급여·기타), 금액, 메모와 수정·삭제 버튼을 보여준다.
- 등록·수정 폼만 팝업으로 연다. 저장하면 팝업을 닫는다.
- 등록 폼의 날짜는 선택한 날짜로 미리 채우며, 다른 날짜로 바꿀 수 있다.
- 기록을 다른 날짜로 수정해도 선택한 날짜는 유지한다.
- 저장한 날짜가 보고 있는 달과 다르면 달력 위에 "○월에 저장되었습니다"를 안내하고, 달력은 보고 있던 달을 유지한다.
- 삭제할 때는 확인 창을 띄운다.

## [금지사항]

- 금지사항을 위반한 소스는 반드시 수정하고 재검증한다. 위반 상태의 구현과 금지 예시는 실제 소스 및 최종 반영 대상에 포함하지 않는다.
- 앞뒤 달 날짜 칸에 기록을 표시하거나 선택 동작을 연결하지 않는다.
- 수입·지출·저축을 색으로만 구분하고 구분 글자를 생략하지 않는다.
- 날짜 칸 클릭으로 팝업을 열지 않는다.
- 달력 칸에 기록 제목이나 금액을 표시하지 않는다.
- 저축을 토요일과 같은 파랑으로 표시하지 않는다.
- 다른 달 날짜로 저장했다고 달력을 저장한 달로 자동 이동하지 않는다.
- 확인 창 없이 기록을 삭제하지 않는다.
- 화면에서 금액 합계를 계산하지 않는다. 합계는 BE 통계 기준을 따른다(표시용 건수 집계는 허용).
- 집계 기간 대신 실제 계좌 잔고처럼 보이는 금액을 표시하지 않는다.
