# 화면 구성

## 최소 화면 구성 제안

| 화면 | 내용 |
| --- | --- |
| 가계부 | 현재 급여 주기 요약, 월 달력과 날짜별 기록, 날짜 팝업에서 수입(급여·기타)·지출·저축 입력 및 수정·삭제. 자동 등록된 기록도 수정·삭제 가능 |
| 통계 | 급여 주기·월·연 선택, 기간별 합계, 연간 월별 표 |
| 반복 설정 | 이름·설명, 수입·지출 구분, 수입 종류, 금액, 매주·매월·매년 주기와 시작일 입력·조회·변경, 이후 자동 등록 중단 |
| 통계 기준 설정 | 통계용 급여 기준일 설정. 설정·변경 정책 확정 후 구체화 |

가계부와 통계에는 실제 계좌 잔고 대신 집계 기간과 기간 잔여액을 표시한다. 반복 설정 변경은 다음 예정 회차부터 적용되고, 과거 기록은 가계부에서 직접 수정한다는 점을 안내한다. 개별 기록 삭제와 이후 반복 등록 중단은 별도 동작으로 제공한다.

## 가계부 화면

### 월 달력

- 첫 화면은 한국 시간 기준 현재 월로 연다. 이전·다음 월로 이동할 수 있다.
- 일요일부터 시작하는 주 단위 달력이다. 앞뒤 달 날짜는 흐린 숫자만 보여주고 기록 표시와 선택은 하지 않는다.
- 넓은 화면에서는 칸마다 기록을 `구분 · 제목 · 금액` 형식으로 보여준다. 제목이 10자를 넘으면 10자까지만 보여주고 `…`을 붙인다.
- 구분은 수입 초록, 지출 빨강, 저축 파랑으로 표시한다. 색만으로 구분하지 않도록 구분 글자를 함께 보여준다.
- 한 칸에 3건까지 보여주고 나머지는 "외 N건"으로 표시한다.
- 좁은 화면에서는 "수/지/저" 색 표시를 최대 3개까지 보여주고 나머지는 "+N"으로 표시한다. 제목과 금액은 날짜 팝업에서 확인한다.
- 칸 안 기록은 등록순(날짜 오름차순, 같은 날짜는 먼저 등록한 기록부터)으로 보여준다.
- 날짜 칸은 "10월 15일, 기록 5건"처럼 날짜와 기록 수를 읽을 수 있는 버튼으로 제공한다.

### 날짜 팝업

- 날짜를 선택하면 팝업이 열리고 그날 기록 목록과 등록·수정·삭제 버튼을 보여준다.
- 등록 폼의 날짜는 선택한 날짜로 미리 채우며, 다른 날짜로 바꿀 수 있다.
- 저장하면 팝업을 닫는다.
- 저장한 날짜가 보고 있는 달과 다르면 달력 위에 "○월에 저장되었습니다"를 안내하고, 달력은 보고 있던 달을 유지한다.
- 삭제할 때는 확인 창을 띄운다.

## [금지사항]

- 금지사항을 위반한 소스는 반드시 수정하고 재검증한다. 위반 상태의 구현과 금지 예시는 실제 소스 및 최종 반영 대상에 포함하지 않는다.
- 앞뒤 달 날짜 칸에 기록을 표시하거나 선택 동작을 연결하지 않는다.
- 수입·지출·저축을 색으로만 구분하고 구분 글자를 생략하지 않는다.
- 제목 말줄임을 UTF-16 단위로 잘라 이모지를 깨뜨리지 않는다.
- 다른 달 날짜로 저장했다고 달력을 저장한 달로 자동 이동하지 않는다.
- 확인 창 없이 기록을 삭제하지 않는다.
- 화면에서 일별·월 합계를 직접 계산해 표시하지 않는다. 합계는 BE 통계 기준을 따른다.
- 집계 기간 대신 실제 계좌 잔고처럼 보이는 금액을 표시하지 않는다.
