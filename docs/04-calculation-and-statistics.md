# 계산 및 통계 정책

## 계산 및 기간 기준

수입·지출·저축의 계산, 잔액 이월 제외, 반복 등록 정책은 확정 기준이다. 급여 주기의 구간은 기존 제안을 유지하며, 통계용 급여 기준일의 설정·변경 정책은 [미정 사항](06-open-questions.md)에서 관리한다.

| 항목 | 기준 | 의미 |
| --- | --- | --- |
| 수입 | 급여·기타 수입을 직접 등록하거나 반복 수입으로 설정 | 저장된 수입 기록을 합산 |
| 금액 단위 | 원화 정수 | 소수점 금액을 다루지 않음 |
| 날짜 | 한국 시간 기준 날짜 | 기록과 통계에 동일한 날짜 기준 적용 |
| 급여 주기(제안) | 통계용 급여 기준일 포함 ~ 다음 기준일 미포함 | 기준일이 25일이면 10월 25일~11월 24일 |
| 월 통계 | 매월 1일~말일 | 해당 월에 발생한 내역 집계 |
| 연 통계 | 매년 1월 1일~12월 31일 | 해당 연도에 발생한 내역 집계 |
| 저축 | 기간 잔여액에서 차감, 소비 지출과 별도 집계 | 저축을 소비로 계산하지 않음 |
| 잔액 이월 | 하지 않음 | 각 기간을 독립적으로 계산 |

### 계산식

```text
기간 수입 = 해당 기간의 급여·기타 수입 기록 합계
기간 지출 = 해당 기간의 지출 내역 합계
기간 저축 = 해당 기간의 저축 내역 합계
기간 잔여액 = 기간 수입 - 기간 지출 - 기간 저축
```

수입·지출·저축은 개별 기록의 날짜가 포함된 기간에 집계한다. 급여 주기·월·연 통계는 같은 기록을 서로 다른 기간으로 조회하며, 통계 조회 자체가 수입·지출 기록을 생성하지 않는다.

기간 잔여액은 해당 기간의 수입에서 지출과 저축을 뺀 값이다. 이전 기간의 잔액을 이월하지 않으며, 실제 은행 잔고를 의미하지 않는다.

통계는 저장된 개별 기록만 합산한다. 반복 설정의 현재 금액으로 과거 기록을 재계산하지 않으며, 아직 등록되지 않은 미래 예정 회차는 합계에서 제외한다. 예정일에 자동 등록된 기록은 합계에 포함되므로, 실제와 다르면 사용자가 수정·삭제한다.

### 반복 등록 정책

- 한국 시간의 날짜를 기준으로 시작일부터 반복한다. 매주는 시작일의 요일, 매월은 시작일의 일자, 매년은 시작일의 월·일을 기준으로 한다.
- 해당 날짜가 없으면 해당 월 말일에 등록한다. 매월 31일은 2월 말일에 등록하되 3월에는 다시 31일을 사용한다. 매년 2월 29일은 평년에 2월 28일, 윤년에 2월 29일을 사용한다.
- 자동 등록 시 해당 회차의 예정일을 기록 날짜로, 당시 설정의 금액과 이름·설명을 개별 기록의 값으로 저장한다. 누락 회차를 뒤늦게 등록해도 실행일로 기록하지 않는다.
- 같은 반복 설정의 같은 회차는 한 번만 등록한다. 개별 기록의 날짜를 수정하거나 기록을 삭제해도 해당 회차의 처리 이력을 유지하여 다시 생성하지 않는다.
- 서비스가 실행되지 않아 누락된 회차는 다음 실행 시 오늘까지 보충한다. 반복 설정 변경 전에는 오늘까지 도래한 회차를 기존 설정으로 처리하고, 다음 예정 회차부터 새 설정을 적용한다.
- 반복 설정을 중단할 때도 오늘까지 도래한 회차를 처리한 뒤 이후 자동 등록을 중단한다. 이미 등록된 기록은 유지한다.
- 모든 수입·지출은 직접 등록·수정·삭제할 수 있다. 개별 기록을 수정·삭제해도 반복 설정과 다른 회차는 변경하지 않는다.
- 반복 등록은 수입·지출만 지원한다. 저축은 직접 기록한다.

예를 들어 매월 월세가 500,000원이고 10월 회차 처리 후 550,000원으로 변경하면, 10월 기록은 500,000원으로 유지되고 11월 예정 회차부터 550,000원으로 등록된다. 과거 금액을 정정하려면 해당 기록을 직접 수정한다.

### 계산 예시

통계용 급여 기준일 25일과 다음 기록만 존재한다고 가정한다.

| 날짜 | 구분 | 금액 |
| --- | --- | ---: |
| 2026-10-25 | 급여 | 3,000,000원 |
| 2026-10-26 | 지출 | 50,000원 |
| 2026-10-27 | 저축 | 500,000원 |
| 2026-10-28 | 기타 수입 | 200,000원 |
| 2026-11-01 | 지출 | 100,000원 |

- 급여 주기 통계(10월 25일~11월 24일): 수입 3,200,000원, 지출 150,000원, 저축 500,000원, 잔여액 2,550,000원
- 10월 통계: 수입 3,200,000원, 지출 50,000원, 저축 500,000원, 잔여액 2,650,000원
- 11월 통계: 위 내역만 존재한다면 수입 0원, 지출 100,000원, 저축 0원, 잔여액 -100,000원
- 2026년 통계: 위 내역만 존재한다면 수입 3,200,000원, 지출 150,000원, 저축 500,000원, 잔여액 2,550,000원

월 경계를 넘는 급여 주기와 달력 기준 월 통계는 집계 대상이 다르므로 잔여액이 다를 수 있다.
