# 요구사항

## 목적

수입·지출·저축을 직접 기록하고, 기간별 잔여액과 통계를 확인하는 개인 가계부 사이트를 만든다. 은행 연동 없이 입력한 내역을 관리하며, 반복 설정한 수입·지출은 예정일에 자동 등록한다.

현재 단계는 요구사항 문서 작성이다. 앱 구현과 기술 구성의 세부 결정은 이후에 진행한다.

## 확정된 요구사항

- FE: React
- BE: Node.js
- 급여·기타 수입과 일별 지출·저축 기록
- 모든 수입·지출·저축 기록의 등록·수정·삭제
- 매주·매월·매년 반복 수입·지출의 예정일 자동 등록
- 잔액 이월 없이 기간별 수입·지출·저축과 잔여액 확인
- 급여일 기준 통계, 월 통계, 연 통계 제공
- 초기 버전은 핵심 가계부 기능에 집중

## 초기 기능 범위

### 급여와 통계 기준

- 급여는 수입 기록으로 직접 등록하거나 반복 수입으로 설정한다.
- 통계용 급여 기준일과 실제 수입 기록일은 구분한다. 급여 기준일의 설정·변경 정책은 구현 전에 결정한다.

### 일별 기록

- 날짜, 구분(수입·지출·저축), 제목, 금액, 선택 메모를 입력한다. 수입은 급여·기타 수입으로 구분한다.
- 제목은 필수다. 앞뒤 공백을 제거한 값을 저장하며 1~50자여야 한다. 글자 수는 이모지를 포함해 문자(코드포인트) 단위로 센다.
- 기록은 월 달력에서 날짜별로 확인하고, 날짜를 선택해 그날의 기록 목록과 등록·수정·삭제를 처리한다. 화면 상세는 [화면 구성](02-screens.md)을 따른다.
- 수동·자동 등록 여부와 관계없이 모든 수입·지출·저축 기록을 수정하거나 삭제한다.
- 금액은 양수로 입력하고, 수입은 더하며 지출·저축은 차감한다.
- 잔여액이 음수가 되더라도 실제 지출을 기록할 수 있어야 한다.

### 반복 수입·지출

- 이름·설명, 수입·지출 구분, 금액, 반복 주기(매주·매월·매년), 시작일을 설정한다. 반복 수입도 급여·기타 수입으로 구분한다.
- 예정일에 개별 가계부 기록을 자동 등록하고 통계에 반영한다. 실제 발생하지 않았거나 금액·날짜가 다르면 해당 기록을 직접 수정·삭제한다.
- 반복 설정 변경은 다음 예정 회차부터 적용한다. 이미 등록된 기록은 자동으로 변경하지 않는다.
- 개별 기록의 수정·삭제는 반복 설정이나 다른 회차에 영향을 주지 않는다. 이후 자동 등록을 중단하는 동작은 별도로 제공한다.
- 반복 날짜 보정과 누락·중복 처리 기준은 [계산 및 통계 정책](04-calculation-and-statistics.md)을 따른다.
- 저축의 반복 등록은 초기 범위에 포함하지 않는다.

### 잔여액 및 통계

- 현재 급여 주기의 시작일·종료일과 수입·지출·저축·잔여액을 표시한다.
- 급여 주기, 월, 연 단위로 기간을 선택하여 조회한다.
- 연 통계에서는 월별 수입·지출·저축·잔여액을 함께 표시한다.
- 집계에 사용한 기간을 화면에 명확히 표시한다.
- 잔여액은 해당 기간의 수입에서 지출·저축을 뺀 값이며, 이전 잔액을 이월하지 않는다. 실제 계좌 잔고나 사용 가능 금액으로 표시하지 않는다.

초기 버전에서는 숫자 요약과 표를 우선한다. 차트, 은행 연동, 외부 거래 내역 자동 수집, 예산 알림, 투자 수익 계산은 현재 범위에 포함하지 않는다.

## [금지사항]

- 금지사항을 위반한 소스는 반드시 수정하고 재검증한다. 위반 상태의 구현과 금지 예시는 실제 소스 및 최종 반영 대상에 포함하지 않는다.
- 제목 없이, 공백만 있는 제목으로, 또는 51자 이상의 제목으로 기록을 저장하지 않는다.
- 제목 길이를 UTF-16 길이(`title.length`)로 세어 이모지 제목을 잘못 거부하거나 허용하지 않는다.
- 금액 0 이하나 유효하지 않은 날짜의 기록을 저장하지 않는다.
- 이전 기간의 잔여액을 다음 기간으로 이월하거나 잔여액을 실제 계좌 잔고·사용 가능 금액으로 표시하지 않는다.
- 반복 설정 변경을 이미 등록된 기록에 소급 반영하지 않는다.
- 저축 반복 등록, 차트, 은행 연동, 외부 거래 내역 자동 수집, 예산 알림, 투자 수익 계산을 초기 범위에 넣지 않는다.
